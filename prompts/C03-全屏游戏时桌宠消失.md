# C03 鲸鱼插件：全屏游戏中点击后桌宠消失（Bug 修复）

**前置**：C01 已在 `whaledot-local` 分支提交且工作区干净。本任务排在 C02 之前。

## 用户报告（Windows 11，DSH Desktop 0.2.1-rc.2，日常 profile）

- 在**全屏**游戏（如《杀戮尖塔》）中，**左键或右键**点击后，桌宠消失。
- 退出游戏后桌宠**仍然不在**；托盘菜单显示的是 **“显示”**（即 `trayState` 认为窗口不可见：`win.isVisible()` 为 false）。
- 用户期望：**默认在全屏游戏上方也保持显示**（回合制/慢节奏游戏里有她陪着正好）；“全屏时隐藏”只能是可选项，默认关闭。

## 已知代码事实（以当前源码为准再核对）

- `desktop/main.cjs`：窗口 `transparent`、`frame: false`、`skipTaskbar: true`、`alwaysOnTop: true`，创建后 `setAlwaysOnTop(true, 'floating')` 只设置一次；`setVisibleOnAllWorkspaces(true, { visibleOnFullScreen: true })`。
- 只有 `hide()`（托盘、菜单“隐藏”、host 的 `control: hide`）会主动隐藏窗口；**没有**处理 `minimize`、被系统隐藏或失去置顶的恢复逻辑。
- 初步判断：全屏游戏获得前台时，Windows 将桌宠窗口最小化或隐藏，或使其失去置顶；Electron 在 Windows 上对最小化窗口的 `isVisible()` 返回 false，与托盘显示“显示”一致。**这是推断，尚未复现，必须先用诊断确认。**

## 第一部分：诊断（先做）

1. 在主进程记录窗口生命周期事件到现有诊断机制（参照 `docs/diagnostics-contract.md`，不新增未声明的诊断文件格式）：`minimize`、`restore`、`hide`、`show`、`blur`、`focus`、`always-on-top-changed`、`display-added/removed/metrics-changed`、`powerMonitor` 的锁屏与休眠事件。每条带时间、`isVisible()`、`isMinimized()`、`isAlwaysOnTop()`、`desiredVisible`、窗口 bounds 与所在显示器的 workArea。**不记录**任何其他应用的窗口标题或进程名。
2. 写一个临时的复现说明（放进回报），让用户在日常 profile 中复现一次并导出诊断（或给出用户可以执行的步骤，由用户执行后把诊断发回）。在没有用户诊断数据之前，可以先完成第二部分，但回报中要写明“根因尚待诊断确认”。

## 第二部分：修复

1. **自动恢复**：当 `desiredVisible === true`（用户没有主动隐藏）时：
   - 收到 `minimize` → 立即 `restore()` 并 `showInactive()`（**不抢焦点**，不能把游戏切到后台）；
   - 窗口被系统隐藏（`hide` 事件但不是由 `hide()` 发起）→ `showInactive()`；
   - 每次 `blur`、`always-on-top-changed`（变为 false）、显示器变化之后，以及在 `desiredVisible` 时每 2 秒一次的轻量巡检：若不可见、被最小化或失去置顶，则恢复并重新 `setAlwaysOnTop(true, level)` + `moveTop()`。巡检只读窗口状态，不得造成可感知的闪烁或抢焦点。
   - 用标志区分“用户主动隐藏”与“系统造成的隐藏”，用户点“隐藏”后绝不自动恢复。
2. **置顶级别**：新增设置项「在全屏应用上方显示」，默认**开启**：开启时使用能覆盖全屏无边框/全屏窗口的置顶级别（在 Windows 上实测比较 `'floating'`、`'pop-up-menu'`、`'screen-saver'`，选能稳定显示在全屏游戏上方且不抢焦点的最低级别，并在回报中写明结论）；关闭时保持 0.4.13 的 `'floating'`。
3. **可选：全屏时隐藏**：新增设置项「全屏应用运行时自动隐藏」，默认**关闭**。开启后，前台为全屏窗口时隐藏、离开全屏后自动恢复（检测方法用 Electron/系统公开能力，写明出处；做不到可靠检测就不做这一项并说明）。
4. **不抢游戏的焦点**：所有恢复与重新置顶操作都用 `showInactive` / `moveTop` 一类不激活窗口的方法；测试中断言恢复后游戏（或测试用的前台窗口）仍保持焦点。
5. 文案与文档：两个新设置项的中英文案；`docs/usage.md` 增加“在游戏中使用”一节（默认会显示在全屏游戏上方；如果挡住游戏操作，可以拖到角落、缩小，或开启“全屏时自动隐藏”）；必要时同步 `docs/desktop-recovery-contract.md` / `docs/multi-display-contract.md`。

## 测试
- 单元：恢复决策的纯函数（输入窗口状态与标志 → 输出要执行的操作），覆盖用户主动隐藏、系统最小化、失去置顶、显示器变化、锁屏/休眠期间不恢复。
- `npm run test:desktop`：用一个测试用的全屏前台窗口模拟“游戏”，对桌宠执行 `minimize()` 与失去置顶，断言自动恢复、仍在最上层、测试窗口保持焦点；用户点“隐藏”后不恢复。
