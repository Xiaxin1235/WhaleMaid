# C08 鲸鱼插件：双击直接和“大肥鱼”聊天

**前置**：C07 已提交，工作区干净；WhaleDot 的 P11 已完成（会话中存在使用 `whaledot-companion` 预设的“大肥鱼”专属会话）。P11 的查证结论见 `D:\dsh_plugins\WhaleDot\docs\dsh-api-notes.md` 第 21–24 节，尤其第 24 节“如何从会话 header 读到 agentPreset”。

## 背景（用户反馈）
现在双击鲸鱼打开聊天，必须先选一个工作窗口（Harness 会话），她没有自己的身份。用户希望双击就直接和她本人聊天。

## 原则
- **不依赖 WhaleDot 的代码**：只通过 DSH 公开的会话信息识别专属会话——会话 header 的 `agentPreset === 'whaledot-companion'`。不 import WhaleDot、不读 WhaleDot 的文件；没装 WhaleDot 时行为与 C07 完全一致。
- 不改动会话发送、草稿、失败重试等既有逻辑，只改“默认选中哪个会话”与界面呈现。

## 要做的事

1. **识别专属会话**：在 host 侧恢复/列出会话时（`src/index.ts` 中会话恢复与 `session/created` 处理），标记 `agentPreset` 为 `whaledot-companion` 的会话为 companion（若有多个，取最近创建且未删除的一个）。作为快照字段下发给渲染页。
2. **默认聊天对象**：新增设置项「双击时默认：和大肥鱼聊天 / 上次的会话」，默认“和大肥鱼聊天”。存在专属会话时，双击打开聊天默认选中它；不存在时退回现有行为。
3. **界面呈现**（新版界面风格）：
   - 选中专属会话时，横幅胶囊显示“和我聊天”（而不是会话名/工作目录），胶囊仍可点击“换一段”，去选择其他工作会话。
   - 会话列表里专属会话固定排在第一位，显示她的头像与“大肥鱼”，不显示工作目录。
   - 选中其他工作会话时，横幅胶囊显示该会话名，并提供一个“回到和我聊天”的快捷入口。
   - 经典界面风格：同样默认选中专属会话，只做必要的文字区分。
4. **回复与信封**：专属会话的回复照常进入气泡与信封；信封中的来源显示“大肥鱼”。
5. 中英文案进 locale；同步 `docs/usage.md` 与 `docs/session-chat-contract.md`。

## 测试
- 识别：header 带/不带 `agentPreset`、多个专属会话、专属会话被删除后回退。
- 默认对象设置两种取值；没有专属会话时与 C07 行为一致。
- 新版/经典两种风格下的横幅与会话列表呈现；“换一段”与“回到和我聊天”。
- `npm test`、`npm run test:inbox-ui` 通过；`npm run test:desktop`（125%）通过。
