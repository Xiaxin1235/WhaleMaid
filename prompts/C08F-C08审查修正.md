## 要修的问题

### 1. 旧的伴侣会话也被当成“大肥鱼”（必须修）

- WhaleDot 每次“开一个新对话”都会保留旧的伴侣会话（最多 20 个），它们的 header 同样是 `agentPreset: 'whaledot-companion'`。隔离环境现在就有 3 个。
- `web/pet.js` 的 `isCompanionSession` 把 `s.agentPreset === 'whaledot-companion'` 也算作伴侣，结果：会话列表置顶好几个“大肥鱼”；选中旧的时“回到和我聊天”不出现；气泡、阅读器、信封都显示“大肥鱼”。而 `desktop/tray-state.cjs` 只认当前那个，两处不一致。
- 修正：**“当前伴侣”只认 `snapshot.companionSessionId`**（host 侧 `PetModel.refreshCompanion` 已按 `createdAt` 选出最新一个，保留）。渲染页与托盘共用同一个判断，不要各写一份。
- 旧伴侣会话按普通会话排序，不置顶，显示名为“大肥鱼（旧对话）” / “Dafeiyu (earlier chat)”，不显示工作目录（目录是 WhaleDot 的内部数据目录，对用户没有意义）；来源显示同理。为此给快照里的会话加一个明确字段（例如 `companionRole: 'current' | 'earlier' | undefined`），由 host 计算，渲染页只读它。

### 2. “回到和我聊天”按钮被挤成竖排（必须修）

- 上一版截图 `03-work-session-back-to-companion.png`：新版界面里这个按钮被挤成一字一行的竖条。原因是它被移进了 `.conversation-heading`（flex 列，`min-width: 0`），按钮自身没有禁止换行与收缩。
- 修正：按钮单行显示（`white-space: nowrap; flex: 0 0 auto`，或与会话胶囊放在同一行的横向容器里），在 100%、125%、150% 文字缩放下都不换行、不溢出卡片；与胶囊垂直对齐。经典界面也检查一遍。
- 在 UI 测试里加断言：按钮可见时，其高度不超过一行文字高度的 1.6 倍，宽度大于文字宽度（防止再次被挤压）。只看截图不算验证。

### 3. “上次的会话”设置下仍被拉回大肥鱼

- `PetModel.remove` 在选中的会话被删除时，回退目标改成了 `companionSessionId`，没有考虑 `defaultChatTarget: 'last'`。
- 修正：恢复 C07 的回退规则（选第一个剩余会话），不在 model 里做“偏向伴侣”的选择；“默认选中大肥鱼”只发生在双击打开聊天时（`openChat` 已处理）。

### 4. 经典风格下的转交口吻

- 经典界面选中大肥鱼时仍显示“消息交给「大肥鱼」，完成后只展示最终回复。”和按钮“捎给这段对话 ↗”。和她本人聊天时应是对话口吻。
- 修正：选中当前伴侣会话时，提示改为“直接和我说就好，我会在这里回你。” / “Just talk to me — I’ll reply right here.”，发送按钮改为“发送” / “Send”。中英文案进 `web/locale.js`；工作会话保持原文案。

### 5. 会话列表点选后的行为

- 现在：有伴侣时，在列表里点选一个会话会回到聊天面板；没有伴侣时只关闭列表（C07 原行为）。
- 保留这个差异（没有伴侣时必须与 C07 一致），但在 `docs/session-chat-contract.md` 里写明原因：有伴侣且默认对象为大肥鱼时，双击总会回到大肥鱼，所以从列表选中工作会话后必须直接回到聊天面板，否则用户无法和工作会话聊天。补一个 UI 测试覆盖“选工作会话 → 发消息 → 回到和我聊天”。
