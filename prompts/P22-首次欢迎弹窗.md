# P22 WhaleMaid：首次欢迎弹窗

**前置**：`master` 工作区干净（本提示词和 `prompts/I1-主动性引擎第一阶段.md` 两个未跟踪文件除外），先跑一遍 `pnpm install --frozen-lockfile`、`pnpm build`、`pnpm test`，确认基线通过。

> **改名说明**：项目已从 WhaleDot 改名为 WhaleMaid（包名 `dsh-whalemaid`、`@whalemaid/core`）。以下内容**有意保持旧名**，不要改：本地目录 `D:\dsh_plugins\WhaleDot`、插件配置 ID 和数据目录 `whaledot`、大肥鱼预设 `whaledot-companion`、隔离 profile `whaledot-p02`。

## 目标

用户装好（或升级到）这一版后，第一次打开 Harness 时看到一个欢迎弹窗：欢迎使用、几项主要功能、交流群，配一个俏皮的大肥鱼比心动图。**每个数据目录只显示一次**，关掉之后，重启、重新登录、换个浏览器打开都不再出现；面板里留一个入口可以再次打开。

## 先查证（写进报告，附代码出处）

1. Harness 客户端插件有没有可用的**全局弹窗或浮层**能力（`@deepseek-ai/dsh-client-ui-*` 里的 dialog、modal、overlay、toast、slots 等），能否在 Harness 启动后、不打开 WhaleMaid 面板的情况下显示。
   - 有：用它，在客户端连上宿主、读到“未看过”后显示。
   - 没有：退而求其次——在用户第一次打开 WhaleMaid 面板时显示，并在侧边栏入口上加一个小红点或“新”标记引导点开（如果有公开能力）。写明采用了哪种、为什么。
2. “已看过”记录放在哪里：用 WhaleMaid 自己的存储（例如现有 `companion_recall_state` 式的键值记录，或新的小表），**不要用浏览器 `localStorage`**——同一台机器换浏览器、清缓存、桌面版与网页端都应只看一次。确认面板 API 新增两个方法（读取状态、标记已看过）的现有写法。
3. 多个客户端同时在线时，一个客户端关掉弹窗后，其他客户端是否能收到变化并收起（或至少下次不再弹）。

## 显示规则

- 记录 `welcome.seenAt`（时间）和 `welcome.version`（弹窗内容版本，从 `1` 开始）。**本次只按“是否看过”判断，不随插件版本自动重弹**；`version` 只为以后的大更新预留，这次不要实现“新版本再弹一次”。
- 新安装和从旧版升级的用户都会看到一次。
- 点“开始使用”、右上角关闭、按 Esc、点遮罩，都算看过并写入记录；写入失败时本次照样关掉，下次再显示，不报错打扰。
- 存储不可用（WhaleMaid 处于只读或错误状态）时不弹。
- WhaleMaid 面板中加一个“欢迎与介绍”入口（放在不显眼的位置，例如面板底部或标题旁的小链接），可随时重新打开同一个弹窗；从这里打开不改变记录。

## 内容（中英文，跟随现有 `language` 设置）

文字由你按下面要点写，保持简短，整个弹窗一屏放得下，不出现滚动条（窄窗口时允许滚动）：

1. **标题**：欢迎使用 WhaleMaid / Welcome to WhaleMaid，一句话说明：给它一个目标，它会在后台推进，需要你拍板时再来问你。
2. **功能介绍**（4–5 条，每条一行图标或小标 + 一句话）：
   - 目标与后台自动推进，独立验收；
   - 需要你决定时，桌宠和面板里给出几个选项，点一下就行；
   - 伙伴“大肥鱼”：记得你的项目，每天一份简报；
   - 主动性：发现反复失败、快停滞等情况，提前告诉你；
   - 安全：授权范围、全局暂停、危险命令需要你确认。
   - 具体措辞以当前 `docs/usage.md` 实际支持的功能为准，不要写尚未实现的东西（例如主动性的建议卡和询问）。
3. **交流群**：测试与反馈 QQ 群 **1001092170**，带“复制群号”按钮（复制后按钮短暂显示“已复制”）；再放一个 GitHub Issues 链接 `https://github.com/Xiaxin1235/WhaleMaid/issues`。
4. **提醒**：WhaleMaid 已自带配套桌宠，不要再单独安装 Coopanion。
5. **按钮**：“开始使用”（主按钮）、“查看使用说明”（打开仓库中的使用说明链接，中英文各自对应）。

## 大肥鱼形象（作者另行绘制，你只负责接入）

形象图由作者单独绘制（绘制要求见 [P22A-大肥鱼欢迎形象绘制.md](P22A-大肥鱼欢迎形象绘制.md)），**你不要自己画，也不要生成或下载任何图片**。

- 约定文件位置（按现有客户端静态资源的打包方式确定实际目录，写进报告）：
  - 动图：`welcome/dafeiyu.gif`（作者也可能给 `dafeiyu.webp` 动图，两种扩展名都要支持，优先 webp）；
  - 静止图：`welcome/dafeiyu-still.png`，用于 `prefers-reduced-motion` 和动图加载失败。
- 文件还没放进来时：弹窗照常工作，形象位置留空（不显示破图图标，不占用异常空间），构建和测试都要通过。可以先放一张 1×1 透明占位，并在报告里写清作者要替换的路径。
- 显示尺寸约 140–160px 高，保持比例；深浅色主题下都放在弹窗顶部或左侧，`alt` 为“大肥鱼在比心”/“Da Fei Yu making a heart”。
- 不加外部图片请求；图片作为打包内静态资源，包清单检查要包含它，并限制单个文件不超过 600 KB（超出时构建检查给出明确报错）。
- **署名**：在 `THIRD_PARTY_NOTICES.md`（没有就在 README 致谢处）加中英文各一句：欢迎弹窗中的大肥鱼形象为作者另行绘制的同人形象；角色原设「溟月」（上善无形），DeepSeek 女仆装二创参考 ZipZipPipe；WhaleMaid 的 MIT 许可不授予角色本身的权利。

## 交互与可访问性

- 弹窗用 `role="dialog"`、`aria-modal`、有标题关联；打开时焦点进入弹窗，关闭后回到原处；Tab 在弹窗内循环。
- 窄窗口（宽 375px）下布局不溢出。
- 不阻塞宿主启动和面板其余功能的加载；读取状态失败时静默不弹。

## 不要做

- 不调用模型，不收集或上传任何数据，不发通知，不改桌宠（`../dsh-coopanion` 不动）。
- 不在弹窗里放还没发布的 B 站视频链接（作者发布后另行补上）。
- **不要推送到 GitHub**，只在本地提交。

## 测试

- 状态读写：首次为未看过；标记后为已看过；重启存储后仍为已看过；写入失败时不抛到界面。
- 显示规则：未看过时弹出；看过后不弹；从面板入口打开不改变记录；存储只读或错误时不弹。
- 多客户端：一个客户端标记后，另一个客户端下次加载不弹（若查证确认能实时同步，再加实时收起的测试）。
- 复制群号按钮：调用剪贴板接口，失败时显示群号让用户手动复制。
- 中英文文案齐全（沿用现有 i18n 完整性检查）。
- 全量 `pnpm test`、`pnpm typecheck`、`pnpm lint`、`pnpm format:check` 通过，打包检查包含新增资源。

## 隔离实测

在隔离环境 `whaledot-p02`（`.dsh-dev`，端口 3182，**不碰日常 profile，不在设了 DSH_HOME 的终端里启动桌面版 Harness**）里：

1. 用一个全新的数据目录启动，确认弹窗出现（截图：中文、英文各一张，含大肥鱼形象）。
2. 关闭后刷新页面、重启隔离宿主，确认不再出现。
3. 从面板“欢迎与介绍”入口重新打开，再关掉，确认记录未变、之后仍不自动弹。
4. 用一份已有旧数据的数据目录升级，确认也会显示一次。
5. 375px 宽度下截图一张；开启减少动态效果时确认显示静止图；删掉形象文件后确认弹窗仍正常。
