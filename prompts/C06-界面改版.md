# C06 鲸鱼插件：界面改版——“她在跟你说话”

**前置**：C05 已提交（`965df44`），工作区干净。用户日常 profile 通过 `link:` 使用本仓库构建产物：完成并提交后 `npm run build`，用户完全退出并从开始菜单重开 Harness 即生效。

## 设计依据（必须先看）

- 用户已确认的设计稿：`D:\dsh_plugins\WhaleDot\docs\coopanion\ui-redesign\`
  - `ChatOld / MenuOld / InboxOld.dc.html`：按 0.4.13 截图与源码重画的原版（仅供对照）。
  - `ChatNew / MenuNew / InboxNew.dc.html`：**新版，实现以它为准**。这些是设计工具的源文件（`{{accent}}`、`{{tint}}`、`{{line}}`、`{{band}}` 等为主题色派生值，见各文件底部 `renderVals()`），用其中的**尺寸、间距、颜色、圆角、字号、结构**作为规格；文件里的简笔鲸鱼和“鲸”字头像只是占位。
- 用户意见：顶部一行要活泼、像她（已按“女仆围裙花边 + 她的小脸 + 她的口吻”定稿）；其余部分照新版。

## 总原则

1. **改动集中**：样式尽量写在 `web/style.css`（可新增 `web/redesign.css` 并在 `index.html` 引入）；`web/index.html` 只做实现新结构所必需的改动；**保留所有现有 `id` 与 `data-*` 钩子**，让 `web/pet.js` 的逻辑与测试选择器继续工作。不改 `web/upstream/` 下的上游代码。
2. **新增设置项「界面风格：新版 / 经典」**，默认**新版**；切到经典时完全等同 C05 的外观（用根元素上的 class 切换样式即可）。这样出问题时用户随时能换回去，也便于以后同步上游。
3. **主题色跟随角色配色**：沿用 `web/pet.js` 中已有的 `--accent` 设置（来自角色配色的 `accent`），由它派生 tint（约 8% 透明度）、line（约 18%）、band（与白色混合约 13% 的不透明色）。换装后整套颜色跟着变。
4. **字号缩放**：所有字号继续乘以 `var(--text-scale)`，与现有“文字大小”设置兼容。
5. **可访问性**：正文与灰色说明文字对白底对比度 ≥ 4.5:1（设计稿灰字用 `#5f6672`）；按钮可触达区域 ≥ 32px；装饰元素 `aria-hidden`；所有交互仍是真正的 `<button>` / `<input>`。
6. **字体**：桌宠页面的 CSP 不允许外链（`default-src 'self'`），**不能用 Google Fonts 链接**。把 Nunito（SIL OFL 1.1）的 woff2（400/600/700/800）放进 `web/fonts/`，附 OFL 许可证全文，并在 `THIRD_PARTY_NOTICES.md` 登记；中文仍用系统字体（`PingFang SC`、`Microsoft YaHei`）。若字体文件来源无法确认许可，就不引入 Nunito，改用系统字体并在报告中说明。

## 通用面板样式（三种面板共用）

- 去掉 2.5px 深色描边：改为 `1px solid line`、圆角 26px、白底、阴影 `0 14px 34px rgba(30,45,80,0.14)`。
- **尾巴指向她**：面板边缘加一个 18px 的旋转方块作为尾巴，带与面板一致的边框。尾巴的位置由现有的面板定位逻辑（`web/pet.js` 的 `position()`）计算：面板在她上方时尾巴在底边，在下方时在顶边，水平位置对准她的中心（夹在面板圆角以内）。
- **顶部“围裙花边”横幅**（三种面板一致）：
  - 横幅占满面板宽度，`band` 底色，上方圆角与面板一致；下沿是波浪褶边：高 8px，用 `radial-gradient(circle at 8px 0, band 7px, transparent 7.5px)`、`background-size: 16px 8px` 横向重复（见设计稿）。
  - 左侧**她的头像**：52–54px 圆形，3px 白边，轻阴影，旋转 −6°。图片用现有 `menu-portrait` 的来源（角色缩略图），`object-fit: cover`、`object-position` 取上方，让脸部居中；缩略图不可用时退回现有的 `menu-emblem`。
  - 中间三行：主题色小字身份行（带小图标）、18–19px 粗体的一句话（她的口吻）、一个白色半透明胶囊（会话名/状态/计数）。
  - 右上角 2–3 个半透明描边小圆圈作为气泡点缀；关闭按钮为 30px 白色圆钮。
- 去掉界面文案里所有表示外链的 `↗`（真正打开外部网页的链接除外），例如“读完整回复 ↗”改为“看全文”，“继续对话 ↗”改为“继续聊”，“捎给这段对话 ↗”改为发送按钮。

## 聊天面板（双击打开）——对照 `ChatNew.dc.html`

- 横幅：身份行“大肥鱼”（喷水小图标）、标题“我在呢～慢慢说！”、胶囊里是当前会话名 + 下拉箭头，点击等同现有“换一段”。
- 她的上一句话：做成对话气泡（圆角 `18px 18px 18px 6px`，`tint` 底），右下角“看全文”文字按钮（等同现有“读完整回复”）。
- 一行快捷按钮（胶囊描边）：打个招呼、给我打气、回到会话。
- 输入：圆角胶囊输入框 + 36px 圆形发送按钮（向上箭头图标，`aria-label`）。保持现有的多行输入能力（输入框获得焦点并有内容时可以长高，最多约 5 行）、`Ctrl/⌘ + Enter` 发送与草稿保留逻辑。下方一行小字快捷键提示。
- 原有的“消息交给「…」，完成后只展示最终回复”说明文字：只在发送中/发送失败时显示，平时隐藏。
- 发送失败、草稿保留等状态文案沿用现有逻辑，只换样式。

## 右键菜单——对照 `MenuNew.dc.html`

- 横幅：身份行“大肥鱼”、标题“要我做点什么？”、胶囊“● 在这里陪你”（圆点为状态色，文字沿用现有状态文案，如“正在思考”“需要关注”）。
- 两个并排大按钮：**说句话**（主题色实心）与 **换装扮**（描边，打开现有的角色面板）。
- “自主陪伴”从 `<select>` 改为**三段式分段按钮**（关闭 / 安静 / 互动，`role="radiogroup"` + `role="radio"`），绑定原有的选项值与逻辑；原 `<select>` 可保留为隐藏的状态来源或直接替换，测试同步更新。
- 四个开关（散散步、歇一会、提醒我、小小声）改为单列列表：左侧标题+说明，右侧 36×20 的开关，保留 `role="switch"` 与 `aria-checked`。
- 底部：“暂时藏起来”（文字按钮）与“源码 · AGPL”（**必须保留**，AGPL 要求提供源码入口）。
- 原菜单里的陪伴状态说明、“一起活动”“恢复邀请”按钮保留功能，样式与新版统一。

## 小信封——对照 `InboxNew.dc.html`
