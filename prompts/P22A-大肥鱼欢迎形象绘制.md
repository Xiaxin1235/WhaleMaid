# P22A 大肥鱼欢迎形象绘制

用于 WhaleMaid 首次欢迎弹窗（P22）的大肥鱼比心动图。由作者单独绘制或用绘图工具生成，画好后放到 P22 报告里写明的路径即可。

## 交付规格

| 项目     | 要求                                                                                  |
| -------- | ------------------------------------------------------------------------------------- |
| 动图     | `dafeiyu.webp`（动图 webp，优先）或 `dafeiyu.gif`，单个文件不超过 600 KB              |
| 静止图   | `dafeiyu-still.png`，取比心最饱满的那一帧                                             |
| 画布     | 正方形，建议 480×480（弹窗里按约 150px 显示，2–3 倍清晰度足够）                       |
| 背景     | **透明**；边缘不要留白底或灰边，深色、浅色背景上都要好看（可加一圈很细的白色描边）     |
| 循环     | 无缝循环，一轮 2–3 秒，12–24 帧                                                       |
| 构图     | 全身或半身 Q 版，人物居中，四周留约 8% 空白，水花和小爱心不要被裁掉                   |
| 禁止元素 | 文字、水印、签名、任何公司标志（DeepSeek、OpenAI、Claude 等）                         |

## 动作分镜（一轮）

1. 站好，轻轻上下浮动，尾巴慢慢摆。
2. 双手抬到胸前，拇指和食指合成一个心形（或双手在胸前合成一个大爱心），同时歪头、眨一只眼。
3. 手心里“噗”地冒出一颗小爱心，向上飘并淡出；头顶同时喷一小股水花。
4. 手放下，回到第 1 帧，循环。

## 角色要点

- 二头身 Q 版，脸圆，表情开心、俏皮。
- 深蓝到浅蓝渐变的长发，头顶一根呆毛，耳侧有像鱼鳍的发片。
- 白色女仆头饰，发侧一个蓝色蝴蝶结。
- 蓝色大眼睛，带高光。
- 身后一条蓝色鲸鱼尾巴，尾鳍是浅蓝色。
- 蓝白配色的女仆装和白色围裙；围裙中间画一个小水滴或小鲸鱼图案，**不要画公司标志**。

## 动起来的做法（任选）

- **逐帧**：先生成或画出 3–4 张关键姿势（站立、比心、爱心飘起、收手），在 Aseprite、Krita 或 Photoshop 里补中间帧并导出动图。
- **分层动画**：把头发、尾巴、手臂、爱心、水花拆成图层，用 Live2D、Spine 或 After Effects 做轻微摆动和比心动作，导出透明的 webp 或 gif。
- 导出后检查：透明边缘没有锯齿白边；文件不超过 600 KB（太大就减少帧数、降到 360×360，或减少颜色数）。
