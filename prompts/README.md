# 给 GPT 的实现提示词

## 使用方法

每次只发一个任务：

- **P 系列**（改 WhaleDot）：附 **`00-通用上下文.md` 全文**，再加任务提示词全文。
- **C 系列**（改鲸鱼插件 `D:\dsh_plugins\dsh-coopanion`）：附 **`C00-鲸鱼插件通用上下文.md`**，不附 `00`。执行会话必须一开始就能写 coopanion 和 WhaleDot 两个目录，能运行 Git、Chromium 和 Electron。

按顺序执行，一个完成并经审查后再发下一个。P 与 C 改的是不同仓库，可以同时交给两个模型，但真实环境验收共用端口 3182 / 9498，不能同时进行。

桌宠由 `@takboo/dsh-coopanion`（AGPL）提供，WhaleDot 只做 Autopilot 和大肥鱼（见 `docs/架构与开发路线.md` v0.2）。
