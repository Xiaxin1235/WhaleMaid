# P00 仓库脚手架（M0）

## 目标
在 `D:\dsh_plugins\WhaleDot` 建立 pnpm monorepo 骨架，让后续每个包都能独立构建、测试。本任务**不写业务逻辑**。

## 要做的事

1. 根目录：
   - `package.json`（private，`"type": "module"`，`engines.node >=22.19`，`packageManager: pnpm@11.x`），脚本：`build`、`test`、`lint`、`typecheck`、`format`。
   - `pnpm-workspace.yaml`：`packages/*`。
   - `tsconfig.base.json`：strict、`module/moduleResolution: NodeNext`、`target ES2023`、`declaration`、`sourceMap`、`noUncheckedIndexedAccess`、`exactOptionalPropertyTypes`。
   - ESLint（flat config，typescript-eslint）+ Prettier（单引号、无分号、宽 110——与 DSH 社区代码风格一致）。
   - `.gitignore`（node_modules、lib、dist、*.db、.env、coverage）、`.editorconfig`、`.gitattributes`（`* text=auto eol=lf`）。
   - `LICENSE`：MIT。
   - `README.md`（中文为主，含英文一句话简介）：项目定位（DSH 上的 Project Autopilot 插件）、**推荐搭配 `@takboo/dsh-coopanion` 获得鲸鱼桌宠（它是独立项目，AGPL-3.0，WhaleDot 不包含其代码或素材）**、架构链接 `docs/架构与开发路线.md`、开发命令、状态“早期开发中”。
   - `CONTRIBUTING.md`：提交规范、测试要求、“不要提交第三方代码或素材；不要复制 AGPL 代码”。
2. 包骨架（每个都有 `package.json`、`tsconfig.json`、`src/index.ts`、一个能通过的占位测试）：
   - `packages/core` → `@whaledot/core`（依赖 zod）
   - `packages/host` → 包名 `dsh-whaledot`。按 DSH 插件包形态（参考 `%USERPROFILE%\.dsh\plugins\dsh-llm-deepseek-vision\package.json` 与 `%USERPROFILE%\.dsh\profiles\desktop\node_modules\@linxin666\dsh-client-ui-task-board\package.json`）：
     - `main: lib/index.js`、`types: lib/types/index.d.ts`、`"dsh": { "bundle": { "patch": "./cordis.patch.yml" } }`
     - `peerDependencies` 与 `devDependencies` 都包含 `@deepseek-ai/cordis`（版本对齐本机 DSH 实际安装的版本，自己去 node_modules 查）
     - 依赖 `@whaledot/core`（workspace 协议）
     - `keywords` 含 `dsh-plugin`（dshfind 插件市场按 GitHub topic 收录）
     - `cordis.patch.yml`：先只 `insert` 一行 `id: whaledot`，`name: 'dsh-whaledot'`
     - `src/index.ts`：`export const name = 'whaledot'`；`apply(ctx)` 里只打印加载信息（日志方式查证 DSH 插件惯例，如 `ctx.logger`；查不到就用 `console.info` 并加前缀 `[whaledot]`）。**整个 apply 用 try/catch 包住，异常只记录不抛出。**
     - 预留 `src/client/` 目录（放一个 `.gitkeep`），P03 用于 Web UI 半区。
3. vitest 配置（workspace/projects），`pnpm test` 跑所有包。
4. GitHub Actions：`.github/workflows/ci.yml`，`windows-latest` + `ubuntu-latest`，Node 24，pnpm，执行 install/build/lint/test。
5. 开发联调文档 `docs/dev-dsh.md`：说明如何把 `packages/host` 链接进一个**新建的测试 profile**（不要动用户的 desktop/web profile），以及如何在该 profile 中同时装上 `@takboo/dsh-coopanion` 做联调。命令以本机 `dsh --help` / `dsh plugin --help` 的实际输出为准，写之前先运行它们确认。

## 不做
- 不写任何业务模块；不做任何桌面窗口或 Electron。

## 完成标准
- `pnpm install && pnpm -r build && pnpm -r test && pnpm lint` 全部通过。
- 仓库已 `git init` 并有一次文档提交；在此基础上提交：`chore: scaffold WhaleDot monorepo`。`.gitattributes` 引起的已有文档换行变化一并提交即可。
