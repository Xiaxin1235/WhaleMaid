# P00 仓库脚手架（M0）

## 目标
在 `D:\dsh_plugins\WhaleDot` 建立 pnpm monorepo 骨架，让后续每个包都能独立构建、测试。本任务**不写业务逻辑**。

## 要做的事

1. 根目录：
   - `package.json`（private，`"type": "module"`，`engines.node >=22.19`，`packageManager: pnpm@11.x`），脚本：`build`、`test`、`lint`、`typecheck`、`format`。
   - `pnpm-workspace.yaml`：`packages/*`、`apps/*`。
   - `tsconfig.base.json`：strict、`module/moduleResolution: NodeNext`、`target ES2023`、`declaration`、`sourceMap`、`noUncheckedIndexedAccess`、`exactOptionalPropertyTypes`。
   - ESLint（flat config，typescript-eslint）+ Prettier（单引号、无分号、宽 110——与 DSH 社区代码风格一致）。
   - `.gitignore`（node_modules、lib、dist、out、*.db、.env、`~/.dsh` 无关）、`.editorconfig`、`.gitattributes`（`* text=auto eol=lf`）。
   - `LICENSE`：MIT。`NOTICE` 文件说明：代码 MIT；角色素材单独授权，见 `packs/*/LICENSE`。
   - `README.md`（中文为主，含英文一句话简介）：项目定位、架构图（可直接引用 docs）、开发命令、状态“早期开发中”。
   - `CONTRIBUTING.md`：提交规范、测试要求、“不要提交第三方未授权素材”。
2. 空包骨架（每个都有 `package.json`、`tsconfig.json`、`src/index.ts`、一个能通过的占位测试）：
   - `packages/core` → `@whaledot/core`
   - `packages/protocol` → `@whaledot/protocol`（依赖 zod）
   - `packages/host` → 包名 `dsh-whaledot`。按 DSH 插件包形态（参考 `%USERPROFILE%\.dsh\plugins\dsh-llm-deepseek-vision\package.json`）：
     - `main: lib/index.js`、`types: lib/types/index.d.ts`、`"dsh": { "bundle": { "patch": "./cordis.patch.yml" } }`
     - `peerDependencies` 与 `devDependencies` 都包含 `@deepseek-ai/cordis`（版本对齐本机 DSH 实际安装的版本，自己去 node_modules 查）
     - `keywords` 含 `dsh-plugin`（dshfind 插件市场按 GitHub topic 收录）
     - `cordis.patch.yml`：先只 `insert` 一行 `id: whaledot`，`name: 'dsh-whaledot'`
     - `src/index.ts`：`export const name = 'whaledot'`；`apply(ctx)` 里只 `ctx.logger`（若存在，需查证）或 `console.info` 打印加载信息，**整个 apply 用 try/catch 包住，异常只记录不抛出**。
   - `apps/desktop` → `@whaledot/desktop`：此任务只放 `package.json` 与 README 占位，Electron 在 P03 再搭。
3. `vitest.workspace.ts`（或 vitest projects 配置），`pnpm test` 跑所有包。
4. GitHub Actions：`.github/workflows/ci.yml`，`windows-latest` + `ubuntu-latest`，Node 24，pnpm，执行 install/build/lint/test。
5. 开发联调脚本 `scripts/dev-dsh.md`（文档即可）：说明如何把 `packages/host` 链接进一个**新建的测试 profile**（不要动用户的 desktop/web profile），例如：
   ```
   dsh plugin --profile whaledot-dev add link:<repo>/packages/host
   dsh --profile whaledot-dev --dump-config
   ```
   命令以本机 `dsh --help` / `dsh plugin --help` 的实际输出为准，写之前先运行它们确认。

## 不做
- 不写任何业务模块；不装 Electron。

## 完成标准
- `pnpm install && pnpm -r build && pnpm -r test && pnpm lint` 全部通过。
- `git init`（若尚未初始化）并提交一次：`chore: scaffold WhaleDot monorepo`。
