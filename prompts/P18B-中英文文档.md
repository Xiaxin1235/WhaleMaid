## 2. 通用安装说明（新写）

写给**第一次拿到这个仓库的人**，不出现作者本机路径和用户名。以 `docs/日常安装与自查.md` 中已演练过的步骤为基础，改写为通用版本：

1. **前提**：
   - 已安装 DeepSeek Harness Desktop 0.2.1-rc.2 / rc.3，并能正常使用；
   - Node.js ≥22.19，用 `corepack enable` 启用 `package.json` 指定的 pnpm；
   - Git。
2. **获取代码**：克隆仓库，或下载 Release 源码包。克隆地址写 `https://github.com/Xiaxin1235/WhaleDot.git`，并注明仓库目前为私有，需要有访问权限。
3. **构建**：`pnpm install --frozen-lockfile`、`pnpm build`。
4. **生成固定副本**：`pnpm --filter dsh-whaledot deploy --legacy --prod <仓库外的目录>`。说明为什么要用固定副本（以后在仓库里改代码不会影响正在使用的 Harness），以及 `--legacy` 不能省。
5. **安装到 Harness**：
   - 先完全退出 Harness；
   - 用 Harness 自带的 CLI 执行 `dsh plugin --profile <profile> add link:<固定副本路径>`。
   - 写清楚：
     - Windows 下 CLI 的默认位置 `%LOCALAPPDATA%\Programs\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd`；
     - 桌面版默认 profile 名为 `desktop`；
     - 怎样确认 profile 名和安装结果，即 profile 目录下 `package.json` 的 `dsh.profile.bundles`。
   - 提醒：执行前确认终端里没有设置 `DSH_HOME`，并先备份 profile 的配置文件。
6. **启动和首次使用**：从开始菜单启动 Harness，打开侧栏的 **WhaleDot** 面板。建议先在不重要的小项目上试；自动推进需要另外开启。说明数据目录为 `<DSH_HOME>\whaledot`，默认是 `%USERPROFILE%\.dsh\whaledot`。
7. **更新**：拉取新代码 → 重新构建 → 重新生成固定副本 → 重启 Harness。
8. **卸载与回退**：
   - 先停止 Harness；
   - 用 `dsh plugin --profile <profile> remove dsh-whaledot` 移除；
   - 数据目录不会被删除，要不要备份或删除由用户决定。
   
   命令以本机 CLI 的 `--help` 为准，不要凭记忆写。
9. **鲸鱼桌宠（可选）**：WhaleDot 不依赖桌宠。需要桌面角色时，另行安装 [`@takboo/dsh-coopanion`](https://github.com/takboo/dsh-coopanion)，它采用 AGPL-3.0-or-later，安装方法以该项目说明为准。注明：上游版本未必包含与大肥鱼专属对话相关的全部界面配合，显示效果取决于所装版本。**不要**写作者本机 fork 的路径或分支名。
10. **常见问题**：
    - `pnpm deploy` 报错要加 `--legacy`；
    - 面板里看不到 WhaleDot 时，先检查 bundles 列表并重启 Harness；
    - 只支持上述 DSH 版本。
    
    其他问题只写在演练中确实遇到的。
11. **平台**：只在 Windows 上验证过。macOS / Linux 写“未验证”，不要编造路径。

### 演练（必须做）

1. 在 `.dsh-dev/p18b-rehearsal/` 下，从**当前提交的干净克隆**（`git clone` 本仓库到该目录，不用工作区）开始，按中文安装说明逐条执行到“安装并能被加载”为止，使用独立的 `DSH_HOME`。
2. 和 `日常安装与自查.md` 的演练方式一样，用 CLI 在临时 profile 里 add，确认 bundles 中出现 `dsh-whaledot`，宿主能加载插件；然后执行 remove，确认卸载成功。
3. 演练命令与输出摘要写进报告。说明中凡是没演练到的步骤，都要标出来。
4. **不在用户日常 profile 执行任何命令**；不从设了 `DSH_HOME` 的终端启动 Harness 桌面版；演练结束后停止自己启动的进程。
