# C07 鲸鱼插件：新界面小细节打磨

**前置**：C06 已提交（`1f45a23`），工作区干净。用户已在日常 Harness 中目视确认新界面，整体满意。本任务只做下面四处样式打磨，**只影响“新版”界面风格**，经典风格保持不变。完成并提交后 `npm run build`，用户重开 Harness 即生效。

设计参考：`D:\dsh_plugins\WhaleDot\docs\coopanion\ui-redesign\` 中的 `ChatNew` / `MenuNew` / `InboxNew`；C06 截图：`D:\dsh_plugins\WhaleDot\.dsh-dev\c06-evidence\`（`chat-blue.png`、`menu-blue.png`、`inbox-blue.png`）。

## 1. 右键菜单：关着的开关颜色太深

- 现状（`menu-blue.png`）：“散散步”“歇一会”关闭时开关轨道是深灰色，看起来像禁用状态。
- 改为：关闭态轨道用浅灰（约 `#d6d8de`），**圆钮加 1px 中灰描边或轻阴影**，保证非文字元素对比度 ≥ 3:1（WCAG 1.4.11：用圆钮描边/轨道边框满足，而不是把整个轨道涂深）；开启态保持主题色。禁用态（若有）另用降低不透明度区分，不能与关闭态相同。
- 样式位置：`web/redesign.css` 中 `.menu-switches` 相关规则。

## 2. 聊天面板：她那句话的气泡太高

- 现状（`chat-blue.png`）：“看全文”单独占一行，气泡下方留出一大块空白。
- 改为：短句时“看全文”与正文**同一行末尾**（正文在左、“看全文”在右下角对齐，正文较长换行时“看全文”跟在最后一行右侧）；气泡上下内边距收紧到与设计稿一致（约 12px / 14px）；没有“看全文”时（短回复）不预留空间。保留 `max-height` 与滚动逻辑。
- 样式位置：`.chat-previous`、`.chat-reply`、`#chat-read`。

## 3. 会话胶囊里的下拉箭头像字母 “v”

- 现状：横幅里会话名后面的下拉提示看起来像字母“v”。
- 改为：用 12px 的描边 SVG 下拉箭头（与设计稿 `ChatNew.dc.html` 中的 `<path d="M6 9l6 6 6-6">` 一致，`stroke="currentColor"`、`aria-hidden="true"`），与文字垂直居中。若当前是用文字字符或伪元素实现的，替换掉。

## 4. 信封里的选项：系统自带圆圈单选框与卡片风格不搭

- 现状（`inbox-blue.png`）：每个选项卡片左边有系统原生的圆形单选框。
- 改为：**整张卡片作为选择目标**，选中态为 2px 主题色边框 + 很浅的主题色底，未选中为 1px 浅边框白底（与设计稿 `InboxNew.dc.html` 一致）；可在卡片右上角放一个小的自绘对勾/圆点表示选中。
- **必须保留原生 `<input type="radio">`**（`web/inline-questions.js` 第 52–60 行附近创建的那个）：用视觉隐藏的方式（不是 `display:none`），让键盘方向键切换、屏幕阅读器、`:focus-visible` 焦点环与现有测试选择器（`data-inbox-key`、`data-action`）继续工作；卡片在 `:has(input:checked)` / `:has(input:focus-visible)` 时显示对应状态。禁用态（提交中/已结束）卡片降低不透明度且不可点。
