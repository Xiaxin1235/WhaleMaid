# C11：桌宠识别已归档对话

日期：2026-10-25。原定交给 GPT，用户转由 Claude 直接实现。产品仓库 `D:/dsh_plugins/dsh-coopanion`，分支 `whaledot-local`，基线 `c97ad54`，提交 `df3da7f fix: hide archived conversations from the pet lists`。本地提交，未推送。宿主为 DSH Desktop 0.2.1-rc.3。

## 查证

1. **读取归档集合**：Harness 的工作区登记服务（`workspaceRegistry`）有一个同步属性 `archivedSessionIds`，返回全局归档集合，见 `@deepseek-ai/dsh-workspace` 类型定义 `index.d.ts:190–195`。服务**没有**归档变更事件；只有 `workspace/session-activity`（瀑布式）和 `workspace/session-stop`，用于归档前的拦截和停止，不适合拿来通知变更。因此 Host 在启动时读取一次，之后每 2 秒读一次内存中的集合，变化时才下发快照。读取时不依赖该包的类型：通过 `ctx.get('workspaceRegistry')`，取不到服务或读取出错时，按“没有归档”处理。
2. **向已归档会话发消息**：P16 已实测，宿主会先**接受**消息，再在模型步骤前用 archived-session-gate 拦下，回合以 blocked 结束，没有回复。所以桌宠收到的是“已接受”，靠宿主的结果无法给出明确原因。C11 改为在 Host 准入时先检查归档集合，命中就以 `session/archived` 失败并保留草稿。
3. **恢复**：`unarchiveSession` 在同一服务上，但按提示词要求，桌宠不调用它，恢复仍在 WhaleDot 面板或 Harness 里完成。

## 实现

| 文件                                                    | 改动                                                                                                                                                               |
| ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `src/archive.ts`（新增）                                | 读取归档集合；服务缺失或出错时返回空集合                                                                                                                           |
| `src/model.ts`                                          | `PetSession.archived`；`archives(ids)` 更新集合，返回集合是否有变化；快照为每个会话标注 `archived`                                                                 |
| `src/index.ts`                                          | 启动时读取一次，之后每 2 秒读一次，有变化才 `update()`                                                                                                             |
| `src/chat.ts`                                           | 准入时遇到已归档目标，以 `session/archived` 失败                                                                                                                   |
| `web/pet.js`                                            | 列表隐藏已归档会话（当前选中的除外，并标“已归档”）；选中的已归档会话禁用输入和发送，说明行与占位文字显示原因；信封里已归档来源不显示“继续聊”，阅读器隐藏“继续对话” |
| `web/redesign.css`                                      | 新版界面在 `data-archived=true` 时显示说明行。新版界面平时隐藏说明行；实测发现只改 DOM 时用户看不到原因，所以补了这条规则                                          |
| `web/locale.js`                                         | 中英文案：“已归档”、归档说明、`session/archived` 失败原因                                                                                                          |
| `desktop/tray-state.cjs`                                | 托盘列表同样隐藏已归档会话（当前选中的除外）                                                                                                                       |
| `tests/figures.test.ts`、`tests/inbox-receipts.test.js` | 默认并发下偶发超时的两个用例单独设 20 秒，不改断言                                                                                                                 |
| 文档                                                    | `docs/session-chat-contract.md` 新增“已归档会话”；`docs/usage.md` 新增用户说明                                                                                     |

双击时默认打开当前大肥鱼会话（`companionSessionId`），而 P16 从不归档当前会话，所以双击不会进入已归档的旧会话。这一点沿用现有逻辑，没有改动。
