## 实现概要

- **设置**：新增 `quietMode: Volatile<boolean>`，默认 `false`。它走现有的 `preference` 白名单和 `settings.mutate` 保存。设置页、右键菜单和系统托盘都能切换，开关只在宿主确认保存后才翻转。
- **开启后不会主动弹出的内容**：
  - 渲染页拦截回复气泡（`showNextReply`）、通知 / 提问卡（`presentNextNotice`）和 `message.notice` 入口。
  - 陪伴邀请、陪伴反馈和应用提示改为信封里的本地卡片，每种最多一张。
  - 宿主侧不再排入新的投递，也不再领取系统通知。
  - 进入安静模式时撤销待投递的提醒和自动补提醒。
- **保持不变**：信封计数、信封内作答、“稍后提醒”按钮、已读回执、用户主动打开的聊天 / 阅读器 / 菜单、鲸鱼的表情状态。
- **关闭时**：安静期间到达的内容不补弹。之后新到的内容按原逻辑弹出。
- **轻提示**：有新内容时信封计数轻跳一次。开启“减少动态效果”时不跳。

## 审查结论

改动集中在 `web/pet.js`、`src/notification-broker.ts`、`src/index.ts`、设置页、托盘和文档，范围符合 C09，没有改 WhaleDot。

审查时修正了 1 处测试：新增的 `tests/inbox-ui.mjs` 安静模式场景里点击了 `.inbox-read`（“展开全文”）。这个按钮在经典界面下由 `web/redesign.css` 设为 `display:none`，测试在经典风格下超时失败。改为点击回复正文 `.inbox-content`，它在两种风格下都能打开阅读器。产品代码未改。
