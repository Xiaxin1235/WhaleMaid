## 做了什么

- **设置**：默认**关闭**。在 Settings → 桌宠 → 回复情绪表情 中开启，或使用桌宠菜单里的同名开关。
- **判断服务**：OpenAI 官方（默认，`OPENAI_API_KEY`，模型 `gpt-6-luna`）或 OpenRouter（`OPENROUTER_API_KEY`，模型 `openai/gpt-6-luna-decisions`）。每次只调用所选服务，不自动切换或兜底。OpenRouter 是在提示词之外新增的选项，提示词原本写的是“不做多档判断来源”；按 GPT 的设置截图和验收记录，这一项是按用户需要加的。
- **发送内容**：只发最终回复的开头。第一段不超过 120 个 Unicode 字符时只发这一段，否则发前 200 个字符。不附加用户输入、工具结果、文件、会话标题或路径。下列会话一律不发：
  - 标题以 `[WhaleDot]` 开头；
  - 首条消息以 `WhaleDot: execute this single task` 开头；
  - 已归档。
- **密钥**：只从宿主进程的环境变量读取，不写入设置、日志或状态接口；设置里只显示“是否检测到密钥”和本次运行的尝试次数。
- **限制**：同一条回复只判断一次；两个服务合计每滚动小时最多 30 次；超时 3 秒；不重试。置信度低于 0.5 或结果为 `neutral` 时不做表情。
- **表情**：持续约 2.5 秒。任务执行、等待、出错时，任务状态优先；拖拽中或开启“减少动态效果”时不播放；安静模式下照常做表情，但不弹框。

## 审查要点

`src/reaction-decider.ts`：

- 请求只含回复开头（`reactionExcerpt`）；
- 返回值严格校验：choice、confidence 和完整的 probabilities 都要合法；
- 日志只有表情、置信度和耗时，没有 Key，也没有回复原文；
- 收到结果后，会重新检查开关、所选服务、会话是否仍然合格、是否仍是最新回复，任一不满足就丢弃。
