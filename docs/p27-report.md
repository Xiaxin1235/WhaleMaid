# P27 女仆宅邸

WhaleMaid 1.6.0 本地候选。宅邸和桌宠暂离分别默认关闭。

## 查证与实现

| 查证项       | 接入方式                                                                                                                                                                                                                                                         |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 面板与可见性 | WhaleMaid 通过 Harness `main` 插槽注册面板。宅邸是面板内的新标签，借助 `layout.panelInfo` 和浏览器 `visibilitychange` 判断是否可见。离开标签、页面隐藏或组件卸载时停止快照轮询、Canvas 绘制与舞台。见 [面板入口](../packages/host/src/client/index.ts)。         |
| 目标和任务   | 读取目标、任务、运行、当前授权与全局暂停，目标摆件按任务 ID 生成。水缸使用最近一次独立验收已解析的通过／失败计数。没有结构化步骤总数时，书架为空；检查点只证明一次已保存的进展。见 [只读投影](../packages/host/src/world.ts)。                                   |
| 通知和雷达   | 门上信件和便签指向现有通知中心的决策和主动性卡。D8、D9 复用项目雷达的当前授权与检测口径，D10 复用目标 hold。已完成的目标进入陈列室，使用目标结果、已验收任务数和关联的已保存经历。详见 [P25 可复用数据](p25-report.md#可复用数据)。                              |
| 舞台和回退   | WhaleMaid 只依据 Coopanion `stage/1` 文档，通过 Harness 同源认证路由加载不透明沙箱 iframe，核对来源窗口、来源域与协议版本。舞台就绪后才可持有暂离连接，卸载时中止；失败时请求欢迎页的自有静止立绘。见 [舞台客户端](../packages/host/src/client/world-stage.ts)。 |
| 许可边界     | 房间与摆件用 Canvas 2D 绘制。WhaleMaid 的 MIT 源码与资源没有复制 Coopanion 的实现、角色素材或动画。完整安装包沿用现有独立 npm 依赖的分发方式，Coopanion 保留独立许可证和对应源码。                                                                               |

## 已知限制

- 目前使用宿主系统时区。书架仅在输入有已完成步骤和步骤总数时显示进度，当前任务记录中的检查点无法提供总数。缺少验收计数时水位保持中性。
- 每个房间最多同时绘制 8 件摆件。超出的已验收任务收进柜子；其余任务仍可在列表查看。陈列柜画出前 6 件纪念品，完整陈列通过列表访问。
- 远程验证用同机第二个独立 Chromium 进程；未覆盖反向代理与物理多设备。舞台需要 WebGL，无法加载时使用静态图。快照、绘制和点击均无需模型。
