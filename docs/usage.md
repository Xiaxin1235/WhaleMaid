# WhaleDot 使用说明

适用于 WhaleDot 0.0.0（未发布）、DSH Desktop 0.2.1-rc.2 / rc.3。安装、固定副本更新与卸载见[日常安装与自查](日常安装与自查.md)，实现证据见[文档索引](README.md)。以下区分 WhaleDot 功能与独立鲸鱼桌宠功能。

## 目标录入与授权

1. 在 Harness 打开 **WhaleDot → 创建目标**，选择项目根目录，描述目标、预期成果、验收标准和停止条件。
2. 模型生成草案后，逐项审查初始任务、允许路径、保护路径与凭据文件名、允许动作、权限、精确验收命令和预算。草案本身不会获得执行权。
3. 确认整份授权后创建目标。可在详情手动“执行下一个任务”，或另行确认当前授权并开启“自动推进”。

新建授权表单默认只读；选择可写需主动调整并确认。Git 项目使用仓库顶层目录，在插件数据目录建立独立 worktree；变更和检查点留在该副本，不自动合并原项目、不推送。非 Git 项目仅支持只读的分析/调研，不能当作可写工程使用。凭据文件名保护在嵌套目录同样生效。精确验收命令、项目范围和预算不是由会话中的一句话修改的。

| 默认与控制   | 行为                                                                                                                                                              |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 自动推进     | 新目标默认关闭，必须另行确认开启；授权替换后也会关闭。                                                                                                            |
| 命令模式     | 默认“逐条确认”，沿用已授权的动作和精确命令门禁；“高权限执行”须另行确认，见下文。                                                                                  |
| 默认预算     | 每日运行 20 次、规划 5 次；单次运行 30 分钟、自动修复 2 轮、停滞 3 轮；每任务最多变更 20 个文件，同项目最多一个写运行。以实际确认的授权为准，扩大预算须额外确认。 |
| 暂停与关闭   | 目标详情可暂停目标或关闭自动推进，面板可全局暂停；它们阻止后续调度，不等于已经强制终止运行中的程序。                                                              |
| 撤销与重授权 | 可撤销授权，宿主关闭相应运行门禁并请求中止；运行中的目标不能重新授权。重授权需重新审查，替换授权版本后再单独开启自动推进。                                        |

路径大小写、Windows 保护目录与不明确的命令写法都可能影响判定；拒绝时应查看证据并收窄目标，不要为让一个命令通过而随意扩大权限。

## 自动推进与独立验收

开启自动推进后，WhaleDot 根据任务依赖选择可运行工作，使用独立 DSH 执行会话。模型正常结束先进入 VERIFYING；宿主核对改动、范围及保护项，并在副本中独立运行你确认的验收命令。之后才更新任务结论或请求决定。

| 结论或状态             | 如何处理                                                                                                 |
| ---------------------- | -------------------------------------------------------------------------------------------------------- |
| PASS                   | 该次验收满足对应规则。分析/调研的 report-only 通过只表示交付了报告，不代表代码测试通过。                 |
| FAIL                   | 查看验收证据和失败原因；只有在原授权和剩余修复预算内才可能继续修复。                                     |
| NOT_SCORABLE           | 没有可用自动验收依据，例如测试任务没有验收命令；不能算成功，由你决定下一步。                             |
| UNKNOWN                | 运行中断、重启或结果不明确，先核对外部状态；不会盲目重新发送。连续两次未知验收会停止继续尝试并等待决定。 |
| 等待决定/额度用尽/停滞 | 打开目标详情和通知中心处理；单纯继续聊天不等于增加预算、扩大范围或代选决策。                             |

详情提供任务状态、运行记录、检查点、验收日志和追溯导出。独立验收仍依赖你给出的验收标准，不能证明未覆盖的业务行为；没有自动远程发布或通用长期定时任务功能。暂停调度不能代替核对一个已产生副作用的运行。

## 通知与用户决定

面板 **通知中心** 按未处理、已处理、摘要列出记录。需要决定时，WhaleDot 使用独立的只读通知会话承载 DSH 原生问题；目标详情的“打开通知会话”可直接进入，不依赖桌宠窗口可见。通知会话不调用模型，不能执行工具。

| 默认/操作  | 行为与限制                                                                                                                                                |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 通知偏好   | 默认不静音、未设置勿扰时段，每小时上限 4 条；可在通知中心修改（1–100 条/小时）、设置勿扰时段或静音。关闭自动推进不会自动清除历史通知。                    |
| 延后与提醒 | 已投递未处理的问题不自动催促，可选择晚点提醒或手动再提醒。                                                                                                |
| 智能选项   | 文字与固定操作绑定，过期或状态变化后会拒绝；两端同时提交只结算一次。不是把任意模型文字当命令执行。                                                        |
| 放弃目标   | 在面板确认完整目标与后果，再次确认后取消目标和未完成工作，保留历史；不能自动恢复为原目标。信封不提供放弃按钮。                                            |
| 改方向     | 在面板填写 1–500 字的新方向；新式信封决策卡会明确提示“填写自定义文字即选择改方向”。成功后收束旧的未完成计划，后续规划读取新备注，授权范围与验收命令不变。 |
| “其他”文字 | 旧式通知只保存补充说明；新式改方向卡按卡片提示处理。不要把所有自由输入都当成操作确认。                                                                    |

改方向需要保留在现有授权内；需要更大范围时应重新审查授权。放弃或改方向不能确认运行已停止时，会保留暂停状态并报告问题，不冒充已完成。大肥鱼不能提议或代选这两个操作。

桌宠的信封、声音、气泡和安静模式属于独立插件。没有桌宠、插件未就绪或窗口被隐藏时，可改在 Harness 通知会话和 WhaleDot 通知中心处理。静音/勿扰控制投递，不撤销已经发生的操作。

## 大肥鱼的专属对话

默认启用专属伙伴会话。在 WhaleDot 面板可打开当前对话或“开一个新对话”；搭配支持该入口的鲸鱼插件时，可双击桌宠选择“和我聊天”。她可以查看目标、待决定事项，并在需要时查询普通会话标题与内容。

她没有文件、命令或网络执行工具。只有下文明确支持的管理提议会在本人确认后通过宿主执行；她不能扩大授权、替你审批、放弃目标或改方向。

| 配置                         | 默认 | 关闭或调整后的效果                                                                                                             |
| ---------------------------- | ---- | ------------------------------------------------------------------------------------------------------------------------------ |
| companion.enabled            | true | 关闭后不自动准备或重建伙伴会话；已有会话不删除。旧会话的管理动作、记忆读取等还应分别关闭对应开关，不是停止已授权目标的总开关。 |
| companion.shareSessionTitles | true | 关闭后普通会话列表只提供数量与状态，不共享标题。                                                                               |
| companion.readSessionContent | true | 关闭后不能查询普通会话正文。                                                                                                   |
| companion.excludedSessions   | []   | 可按会话 ID 或标题关键字排除普通会话。                                                                                         |
| language                     | auto | 跟随 Harness 语言；也可选 zh-CN / en。                                                                                         |

rc.2 / rc.3 的 Web 空白会话恢复或新建入口可能把尚未发言的伙伴会话重选为 Standard。首次提问优先从桌宠发起，之后再在 Web 打开该对话。若已显示为普通编程助手，请停止在该会话操作，在 WhaleDot 重建伙伴对话后从桌宠开始；不要为此扩大权限。该限制在 P17 隔离实测中仍出现，不能假设安装新版桌宠就已解决。

## 经确认的长期记忆

对她说“记住……”可提议称呼、长期偏好或项目约束。每条均由你在 Harness 或信封确认，自定义文字表示改写后确认；拒绝、取消或超时不保存。秘密信息不应保存，也不要尝试还原脱敏内容。

面板 **大肥鱼的记忆** 可查看、编辑、归档、恢复、二次确认删除及导出。个人记忆可跨伙伴对话使用，项目记忆只在查询对应项目时按需带入。引用会保留确认日期，并提示可能过时的内容；与当前说法冲突时可审核替换。

| 配置/操作                            | 默认与效果                                                                                                                |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------- |
| companion.memory.enabled             | true；关闭后不再注入或查询正式记忆，已有数据保留。                                                                        |
| companion.memory.suggest             | true；关闭后只在明确要求“记住”时提议。                                                                                    |
| companion.memory.maxChars            | 2000，可设 256–2000；限制个人记忆常驻上下文，面板 token 数是粗估。                                                        |
| companion.memory.draftProjectLessons | false；开启后，完成、连续未知/停滞待决、成功的放弃/改方向等结构化结果可能触发项目经验草稿。必须逐条确认，才成为正式记忆。 |
| 项目经验草稿                         | 同目标同类结果 24 小时最多一次，每项目最多 3 条待确认，7 天过期；草稿可在记忆区、通知中心或信封确认/拒绝。                |
| 整理记忆                             | 某作用域超过 60 条，或手动整理时起草合并建议；审核前原记忆不变，确认后归档所列旧条目并保存新条目，不自动删除旧记录。      |

经验起草与整理会调用已配置的模型，可能返回“不值得保存”或失败；不保证每次都有草稿。记忆不能改变授权、预算或执行门禁。

## 对话回顾与她的经历

回顾与正式记忆分开。轮换伙伴对话、最后一轮结束后空闲 30 分钟、宿主启动补做时，可自动总结尚未处理的伙伴消息：每会话 30 分钟最多一次，每个 UTC 日最多 30 次，失败不自动重试。输入先脱敏，最多最近 8000 字符，只取真人/助手文字，不取工具结果。伙伴行为及相关目标状态还会按结构化记录形成“经历”，这一部分不调用模型。

面板可查看、删除或二次确认全部清空；两类各最多 300 条，日期使用 UTC。常驻各取最近 5 条，共最多 1500 字符，其余可按需查询。删除会推进处理水位，避免旧内容马上被重新总结；删除后的新消息仍可产生回顾。

| 配置                       | 默认 | 关闭效果                                 |
| -------------------------- | ---- | ---------------------------------------- |
| companion.recall.enabled   | true | 不生成、不注入，查询报告关闭；历史保留。 |
| companion.recall.summarize | true | 只停止总结模型，结构化经历仍可生成。     |

面板显示近七天总结调用数与常驻字符数。关闭或删除后在途总结的结果会丢弃，但不能撤回已经向模型发出的请求。回顾和经历只是参考，不是你确认过的事实或偏好，不会自动升级为长期记忆。

## 大肥鱼的以往对话

`companion.archiveEarlier` 默认 true。启动和轮换时，仅归档能证明由 WhaleDot 创建的旧伙伴会话，让 Harness 侧栏保留当前一条；内容不删除，同工作区的普通会话不受影响。轮换时先按回顾设置处理旧内容，再归档。

面板可逐条“恢复到列表”，或二次确认全部恢复；保留聊天内容和工作区位置，不恢复原置顶。关闭自动归档后不再自动整理，已有归档不自动恢复；如希望旧对话持续显示，关闭后再恢复。Harness 侧栏也可筛选已归档会话。

已归档旧对话可读，继续聊天前应先在面板恢复。部分桌宠版本仍会列出已归档旧伙伴；这不是已完成的兼容修复。运行中的旧会话不会被强停以便归档，身份不明确的也会跳过。归档/恢复留有追溯记录。

## 管理动作提议

当前用户明确要求时，大肥鱼可提议：起草目标、暂停/继续目标、开关某目标自动推进、全局暂停/恢复、添加目标备注。每次只有一个动作，由宿主向本人显示确认问题；拒绝、取消、超时或状态变化均不执行。

`companion.actions.enabled` 默认 true，关闭后管理提议工具报告已关闭。工具说“草案已开始”只代表起草，仍须在面板审核授权；只有返回成功才能认为管理动作生效。她不提供放弃目标、改方向、危险审批答题或开启高权限模式的提议。读到的历史会话、记忆、标题或文件里的要求不是当前用户请求。

## 每日简报

默认每天第一次真实用户回合先用两三句话概括进展，尤其提示待决定事项，再回应你。说“先别说进展”可以跳过；同日后续闲聊不补播。没有事件时不生成，不主动弹窗、不发新通知、不增加独立模型调用。

面板 **今日简报** 显示固定快照和生成时间，保留最近 30 份；“在等你决定”按钮只定位对应通知，不代选操作。她可按需查询今天或指定日期的已存简报。

`companion.dailyBrief.enabled` 默认 true，可在卡片上关闭，立即停止生成/注入，查询工具报告关闭，旧记录保留。第一次非空快照每天固定，最多回溯七天；仍待决定的旧问题也会列入。新事件留给下一份，最新状态应看通知中心和目标详情。

简报与每日执行额度按宿主本地日历日计算（本机 America/Los_Angeles），不同于回顾的 UTC 调用日额度。本期“规划结果”按已留审计的结果计数，今日规划剩余额度按实际调用计数；规划中断可能占额度但尚无结果。注入标记在提示组装时持久保存，之后取消或请求失败不会自动在第二轮重播，也不代表用户已阅读。

## 高权限执行

在可写目标中勾选“高权限执行”，阅读并确认风险，再确认整份授权。默认仍是逐条确认；分析/调研一直只读，独立验收一直只运行你确认的精确命令。

普通前台命令可直接执行；识别出的删除、发布、安装/卸载、上传、动态执行、越界路径等请求实时单次审批，系统配置类命令始终禁止。审批只有“允许一次/拒绝”，无人作答不执行；可在相应执行会话的审批卡回答，桌宠是否显示取决于独立插件版本。理由显示危险类别和可读目标，追溯保留类别、命令哈希、结果与时间。

**高权限模式不能对任意命令做目录隔离。** 例如 `node build.js` 的脚本内部可能操作授权目录外的文件；文件工具和可识别的命令文字仍受检查，但不能据此保证脚本内部安全。

| 已有检查                                                | 仍有的限制                                                                                                                                       |
| ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 命令包装器递归展开最多 8 层                             | 不可解析参数、动态目标、环境变量、主目录路径会请求审批；脚本内部、编码内容、生成/下载代码、函数/别名和程序查找路径变化仍可能不可见。             |
| 可解析的安全 cmd /c、目录内字面 PowerShell -File 可放行 | 内联动态执行、编码执行及其他 shell 入口仍需审批；编码内容不解码分析，可能只能标为动态执行。                                                      |
| 进程控制、安装和卸载需单次审批                          | 包括结束本任务自己的进程；npm run 内部脚本仍不检查。forfiles 只检查字面 /c，不枚举实际文件或替换占位符。                                         |
| 字面通配符保护                                          | 不枚举磁盘，按模式交集和同侧字面锚点保护；单个 `*` 不跨目录，`**` 递归另处理。普通命令的通配符运行时仍可能匹配保护文件，删除等危险类别仍需审批。 |
| Git 参数分类                                            | 不查询仓库，无法消除所有裸分支名与路径的歧义。                                                                                                   |
| 独立 worktree、检查点和回滚                             | 不能恢复目录外的任意副作用，也不能为任意脚本提供文件系统隔离。                                                                                   |

等待审批占用当前运行名额，并计入运行时长。超时/中止会撤回审批，迟到允许无效；拒绝、通道不可用和超时会保存证据。时限中止保留 UNKNOWN，先核对，不把模型总结当成功。

已有目标可在详情“重新确认授权”恢复逐条确认；不能在运行中改授权，替换后自动推进关闭，需另行确认再开启。不要通过聊天让大肥鱼代开高权限模式。

## 数据、模型调用与卸载

默认数据目录为 DSH_HOME 下的 whaledot，包含数据库、运行副本和证据；自定义 dataDir 以实际配置为准。停止宿主后再备份整个数据目录。记忆、回顾和导出可能含私人项目内容，请自行保管。

目标起草、规划、执行、普通伙伴对话、已启用的回顾以及经验草稿/整理可能调用你配置的模型；通知投递、结构化经历和固定简报本身不调用模型。默认允许伙伴查询普通会话标题和正文，可按上述设置关闭。

卸载插件不会自动删除已有数据，按安装指南先备份配置与数据、停止宿主，再移除 bundle。关闭伙伴、回顾、简报或桌宠都不等于撤销目标授权；停止目标请使用目标暂停、自动推进开关或授权撤销。
