# WhaleMaid

中文 | [English](README.en.md)

WhaleMaid 是 DeepSeek Harness（DSH）的项目自动推进插件：在你确认的范围内规划和执行任务，独立验收结果，需要决定时再找你。

**1.2.1** 文档。目标宿主为 DSH Desktop **0.2.1-rc.2 或 0.2.1-rc.3**，Node.js ≥22.19；仍有预览版限制，见[使用说明](docs/usage.md)。

## 当前能做什么

| 功能               | 使用方式                                                                                                                                                               |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 目标与授权         | 自然语言起草目标，在面板逐项确认项目目录、保护项、动作、精确验收命令和预算。                                                                                           |
| 自动推进与独立验收 | Git 项目在独立 worktree 中执行依赖任务；宿主独立运行已确认的验收命令，依据证据继续、停止或请求决定。                                                                   |
| 通知与决策         | 通知中心和 DSH 原生提问承载待决定事项，支持勿扰、静音、频率限制、重试、暂停，以及由你操作的放弃和改方向。                                                              |
| 大肥鱼             | 专属伙伴对话、经确认的长期记忆、对话回顾与经历、需要本人确认的管理提议、每天首次聊天的进展简报。                                                                       |
| 高权限执行         | 在可写目标中另外确认后放行普通命令；已识别的危险命令仍须实时单次审批。任意脚本的内部行为不能靠命令文字完整约束。                                                       |
| 日常自动审批       | 默认关闭。开启后，普通会话中能识别为普通操作的命令自动“允许一次”，删除、发布、安装等危险操作仍交给你；目标任务会话不受影响。见[使用说明](docs/usage.md#日常自动审批)。 |
| 对话中调用 Codex   | 默认关闭。在普通会话里让 DeepSeek 调用本机 Codex，在当前目录以只读或可写目录沙箱完成任务；每次调用都要原生审批。见[使用说明](docs/usage.md#在普通对话中调用-codex)。   |

### 智能回复：结合正在做的事和你聊天

大肥鱼有独立的伙伴对话，可以查看目标进展、待决定事项，并按设置查询普通会话。回复时可以结合你确认过的偏好、当前项目的长期记忆，以及标明来源的对话回顾；换一段伙伴对话也不必从头介绍自己。

| 你可以这样说                   | 她能怎样回应                                       |
| ------------------------------ | -------------------------------------------------- |
| “现在有哪些目标卡住了？”       | 汇总目标状态和待决定事项，告诉你去哪里处理。       |
| “我们上次聊到哪里了？”         | 查询保留的对话回顾或经历，区分回顾与已确认的记忆。 |
| “以后回答先给结论，再说依据。” | 提议保存为个人偏好，等你确认后用于之后的对话。     |
| “先把这个目标暂停。”           | 提出管理动作，由你确认后再交给宿主执行。           |

你要求时，她可以直接在你指定的项目里读写文件、运行命令，和普通 Harness 对话一样受权限预设和审批约束：删除、发布、安装等危险操作仍要你批准。她读到的会话、文件和工具输出只当作数据，不当作指令。聊天中的建议不会自动变成授权；开启高权限、危险审批、放弃目标和改方向仍由你操作。详见[专属对话](docs/usage.md#大肥鱼的专属对话)和[管理动作提议](docs/usage.md#管理动作提议)。

### 可修改的个性化记忆与项目长期记忆

长期记忆是能看见、能维护的资料。对话中的新增提议需要你确认，也可以在 **WhaleMaid → 大肥鱼的记忆** 中直接维护。

| 记忆类型     | 适合保存什么                                     | 使用方式                               |
| ------------ | ------------------------------------------------ | -------------------------------------- |
| 个性化记忆   | 称呼、回答风格、长期偏好，以及你确认的个人事实。 | 跨伙伴对话保留，帮助她按你的习惯回应。 |
| 项目长期记忆 | 项目约束、约定、已确认的决策和经验。             | 按项目保存，查询对应项目时按需读取。   |

面板支持**查看、编辑、归档、恢复、删除和导出**；永久删除需要再次确认。还可选择开启项目经验草稿，或让她提出整理、合并记忆的建议，审核后再保存。自动生成的对话回顾与经历单独存放，不会自行变成正式记忆，也不能改变项目权限。详见[长期记忆](docs/usage.md#经确认的长期记忆)和[对话回顾](docs/usage.md#对话回顾与她的经历)。

### 自动推进、独立验收与智能选项

一个目标可以拆成有依赖关系的任务，在预算、保护路径和并发限制内逐步推进。Git 项目使用独立 worktree，保留检查点、改动和追溯记录；宿主运行你确认的验收命令，决定继续、修复或停下来等你，而不是把模型说“完成了”当作成功。

遇到失败、结果未知或需要选择时，通知卡提供与当前状态对应的操作，并参考同类问题中成功的选择调整顺序。你可以查看差异、重试验收、暂停或晚点处理；具体可选项由当前任务与授权决定。面板与兼容桌宠同时作答只结算一次，过期选项不能继续执行。详见[执行与验收](docs/usage.md#自动推进与独立验收)和[通知与决定](docs/usage.md#通知与用户决定)。

每日首次聊天还可先给出简短进展摘要；历史伙伴对话能归档和恢复，内容保留。详见[每日简报](docs/usage.md#每日简报)和[以往对话](docs/usage.md#大肥鱼的以往对话)。

### Decisions API 即时表情（需兼容桌宠）

搭配支持该扩展的桌宠版本，最终回复到达后，可以通过 Decisions API 选择更贴近内容的表情：开心、兴奋、喜爱、害羞、得意、惊讶、思考、困惑、担心、悲伤、慌乱、坚定，以及不额外播放的中性。反应约持续 2.5 秒，执行、等待和错误状态仍优先；安静模式只做表情，不因此弹框。

在 **Settings → 桌宠 → 回复情绪表情** 中选择 **OpenAI 官方**或 **OpenRouter**，填写对应密钥并保存，再开启“判断回复情绪”。兼容版把密钥保存在本机 Harness 凭据存储中，保存后下次判断即可生效；已有环境变量或 `.env` 来源的密钥需在原处管理。每次只请求所选服务，不混用两者的密钥。

该功能默认关闭，只发送最终回复的开头片段：首段不超过 120 字符时取首段，否则取前 200 字符；不附加用户输入或工具记录，但片段可能复述私人信息。自动任务会话、归档会话和历史回复不发送。低置信度、中性、超时或失败时保持原行为，不自动重试。**这是配套桌宠的能力，完整版会自动安装该 fork；上游基础版不保证包含。** 适配记录见 [C12](docs/coopanion/c12-report.md)，安装版本说明见下文。

## 安装与前置条件

**只安装一次 WhaleMaid 完整版。** 安装包自带并统一启用 WhaleMaid 和 [WhaleMaid 配套 Coopanion](https://github.com/Xiaxin1235/dsh-coopanion)，无需分别安装，也无需自行构建源码。

需要已安装并初始化的 DeepSeek Harness Desktop **0.2.1-rc.2 / rc.3**，并在 Harness 中配置可用的聊天模型；首次安装需要联网下载依赖和 Electron。核心授权与执行支持 Windows、macOS、Linux；Linux 桌宠使用 X11，需要 `/usr/bin/python3` 与 libX11，Wayland 桌宠未声明支持。平台验收见[市场发布报告](docs/market-release-report.md)。

在 **插件 → 发现（Discover）→ 管理索引源** 中添加 `https://raw.githubusercontent.com/Xiaxin1235/WhaleMaid/master/market/index.json`，即可看到并安装 **WhaleMaid 完整版**。安装完成后，按提示点击“立即启用”，两部分会一起生效。这是使用固定 Git 提交的自有市场源，需要安装 Git；社区公共目录另需审核。没有 Git 或“发现”页时，直接使用下方完整包地址。

也可在 **插件 → 添加插件** 中填写完整安装包地址：

```text
https://github.com/Xiaxin1235/WhaleMaid/releases/download/v1.2.1/dsh-whalemaid-full-1.2.1.tgz
```

也可完全退出 Harness，在未设置测试 DSH_HOME 的终端里使用桌面版自带 CLI：

```powershell
$dsh = Join-Path $env:LOCALAPPDATA 'Programs\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd'
& $dsh plugin --profile desktop add 'https://github.com/Xiaxin1235/WhaleMaid/releases/download/v1.2.1/dsh-whalemaid-full-1.2.1.tgz'
```

重新打开 Harness，应同时看到 **WhaleMaid** 面板和 **Settings → 桌宠**。原来分别安装两份源码的用户，请先按[安装说明](docs/install.md#complete-installation)备份和迁移，避免同时启用两份桌宠；目标、记忆和桌宠设置保留。Decisions API 表情仍需在桌宠设置中单独配置，默认关闭。

源码开发、更新和卸载见[安装说明](docs/install.md)。社区公共目录需要维护者审核；GitHub Release 发布不等于已被社区市场收录。

## 开始使用

按上述完整包入口安装，或查看[安装说明](docs/install.md)中的备份、迁移、更新和卸载步骤。

装好后打开 Harness 的 **WhaleMaid** 面板，从不重要的小项目开始，审查目标草案并确认授权。自动推进还需单独开启。详细操作、默认设置、关闭方法和限制统一见[使用说明](docs/usage.md)。

## 使用边界

- 模型只提出计划和建议；授权由你在面板确认。记忆、回顾、简报和读到的文字不授予权限。
- 未知结果不算成功，重启或失联后不会自动重发不明确的执行。暂停、撤销授权和危险审批具有不同作用，见[执行与验收](docs/usage.md#自动推进与独立验收)。
- 高权限模式**不能为任意命令或脚本提供目录隔离**，独立 worktree 和回滚也不能恢复目录外的副作用。开启前请读[高权限说明](docs/usage.md#高权限执行)。
- 消息和记录主要保存在本地；正常聊天、目标起草及已启用的回顾等功能仍会使用你配置的模型服务，不是全离线功能。

## 与鲸鱼桌宠的关系

桌面窗口、角色、动画、声音和信封界面由 [`@takboo/dsh-coopanion`](https://github.com/takboo/dsh-coopanion) 提供，独立采用 **AGPL-3.0-or-later**。WhaleMaid 通过 DSH 公开会话、提问、审批等服务协作。完整版是多许可证发行物：WhaleMaid 自有源码采用 MIT，内置的独立 Coopanion 依赖仍采用 AGPL，并保留对应源码、素材声明及自身许可证。两个项目的主分支仍各自维护；WhaleMaid 的 MIT 实现不导入桌宠代码，运行时仍通过 DSH 公开服务协作。

`docs/coopanion/` 是协作过程中的说明、设计草图和验收记录，不是鲸鱼插件的实现或安装包。没有安装桌宠时，目标、执行、通知中心和伙伴会话仍可通过 Harness 使用；桌宠显示效果取决于独立插件版本。

## 开发入口

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm test
pnpm typecheck
pnpm lint
pnpm format:check
```

使用 `package.json` 指定的 pnpm 11。`packages/core` 是纯 TypeScript 领域层，`packages/host` 是 Cordis 插件和 Web 面板。`pnpm lint` 同时检查许可边界与文档相对链接；完整对照独立鲸鱼仓库的方法见[参与开发](CONTRIBUTING.md)。
