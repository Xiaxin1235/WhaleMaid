# WhaleDot

WhaleDot is a Project Autopilot plugin for DeepSeek Harness (DSH).

WhaleDot 在用户授权范围内推进长期项目，计划提供目标与任务管理、独立验收、进度与决策通知。
状态：**早期开发中**。已具备目标录入、授权存储与手动隔离执行；独立验收和自动推进闭环尚未实现。

推荐搭配 [`@takboo/dsh-coopanion`](https://github.com/takboo/dsh-coopanion) 获得鲸鱼桌宠。
它是独立的 **AGPL-3.0** 项目；WhaleDot 为 **MIT**，不包含其代码或素材，也不直接依赖它。
后续协作仅通过 DSH 公开服务与事件进行。桌宠是可选增强。

## 结构与设计

### 大肥鱼的长期记忆

以往伙伴对话默认轮换归档，让 Harness 侧栏保留当前这一条；内容不删除，可在 WhaleDot 面板逐条或全部恢复。普通会话不受影响。桌宠仍可能列出归档旧对话，需要恢复后再继续聊天。关闭自动归档、查看归档和恢复说明见 [使用说明](docs/usage.md#大肥鱼的以往对话)。

对话回顾与她的经历和确认记忆分开保存。切换到新伙伴对话、最后一轮结束后空闲 30 分钟、宿主启动补做时，会自动总结尚未处理的伙伴消息；每会话 30 分钟最多一次、每天（UTC）最多 30 次，失败不重试。仅处理本段对话的真人与助手文字，先脱敏，最多最近 8000 字符；工具结果不进入回顾。她的提议及相关目标后续状态按结构化记录生成经历，不调用模型。

记忆面板可查看、删除或二次确认全部清空，日期使用 UTC。删除也会推进现有伙伴对话的处理水位，避免刚才复述旧回顾的回答又被总结回来；删除之后的新消息仍可生成回顾。两类各最多保留 300 条。常驻上下文最多各取最近 5 条，共 1500 字符；其余可用只读查询工具检索。这些内容只作参考，不是用户确认的事实、偏好或执行依据，不能自动升级为 P12 记忆。

`companion.recall.enabled` 默认 true，面板关闭后不生成、不注入，工具明确返回关闭，已有数据保留；`companion.recall.summarize` 默认 true，单独关闭只停止总结模型，经历仍生成。面板显示近 7 天总结模型调用次数和常驻字符数。已有在途请求不追溯改变，关闭或删除后在途总结的结果会被丢弃。

说“记住……”可提议称呼、长期偏好或项目约束；每条都先在 Harness 或鲸鱼信封中由你确认。自定义文字表示改写后确认，“不用记”、取消和超时均不保存。密钥等秘密不会保存。面板「大肥鱼的记忆」可编辑、归档、恢复、二次确认删除和导出。

个人记忆在新对话中仍有效，常驻上限 2000 字符；项目记忆只在查询对应项目时按需带出，不影响执行授权。`companion.memory.enabled` 默认 true，关闭后数据保留、模型不可读；`suggest` 默认 true，关闭后只在明确说“记住”时提议；`maxChars` 可设 256–2000。常驻块显示字符数和 token 粗估，查询保留确认日期并提示过时记录。

「起草项目经验」默认关闭，可在记忆面板开启。目标完成、连续未知或停滞待决时，大肥鱼根据结构化事实起草一条项目经验；同目标同类结果 24 小时最多一次，每项目最多 3 条待确认草稿。草稿在记忆区、通知中心和信封中确认或拒绝，7 天过期。放弃／改方向的事件监听已准备，决策按钮留到 P13。

某个作用域超过 60 条记忆，或点「整理记忆」，会产生合并建议，供你逐条审核。确认前原记忆不变；确认后才归档所列的旧条目并保存新条目，旧记录不会自动删除。

Desktop 0.2.1-rc.2 的 Web 空白会话入口可能重选 Standard；目前首次提问请使用桌宠的「和我聊天」，随后 Web 可打开同一对话查看和确认。不要为此扩大文件或命令授权。

## 开发

使用 Node.js ≥22.19（推荐 Node 24）和 `package.json` 指定的 pnpm 11。

```sh
pnpm install
pnpm build
pnpm test
pnpm lint
pnpm typecheck
pnpm format
pnpm format:check
```

`pnpm build` 按 workspace 依赖顺序构建；`pnpm test` 使用 Vitest projects 运行全部包。
每个包也可独立执行，例如 `pnpm --filter @whaledot/core build`、`pnpm --filter dsh-whaledot test`。
构建产物为各包的 `lib/index.js`、source map 与 `lib/types/index.d.ts`。

DSH 隔离联调步骤见 [docs/dev-dsh.md](docs/dev-dsh.md)。协作约定见 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 手动执行（P08）

在 WhaleDot 面板确认目标与授权后，目标详情可“执行下一个任务”。Git 项目使用仓库顶层目录，
在插件数据目录创建独立 worktree；不会修改原工作区或推送分支。analyze/research 强制只读，
正常结束进入 VERIFYING；独立验收为后续 P09。撤销、超时或重启后不明确的运行进入 UNKNOWN，
不会自动重发。凭据文件名在任意嵌套目录中受保护；未知工具、越界操作及未确认脚本被拒绝。

实现、测试与手工验收边界见 [P08 报告](docs/p08-report.md)。

## 通知与用户决定（P04/P05）

WhaleDot 面板的“通知中心”按未处理、已处理、摘要显示通知，可以设置勿扰、静音及每小时上限。
需要你决定时，由独立的只读通知会话承载 Harness 问题；目标详情的“打开通知会话”可直接进入，
不依赖桌宠窗口可见。选项带操作说明，“其他”只保存用户补充说明，不执行命令或扩大授权。
已投递但未处理的通知不会自动催促；可手动再提醒或选择一小时后提醒。

通知会话本身不调用模型，所有工具均被门禁拒绝。实现与实际桌宠显示的验收缺口见
[P04/P05 报告](docs/p04-p05-report.md)。
